# ADR — Анимации и UI-источники (MD §16.5)

Решение: **CSS transitions + Motion for React (`motion`, MIT) + Radix/shadcn-подход + lucide-react (ISC)**. Других анимационных библиотек в Фазе 1 нет.

| Библиотека из референса | Решение | Причина |
|---|---|---|
| Motion | **используется** (`motion/react`, лениво через `LazyMotion` + `domAnimation`) | enter/exit панелей и диалогов, прогресс |
| GSAP, Rive, Lottie/dotLottie | не подключены | Не нужны операционному дашборду; лицензии ассетов проверять до использования |
| Aceternity UI, Magic UI | не подключены | Только вдохновение; код motion-heavy, лицензию пришлось бы проверять поштучно |
| Framer (сайт) | не используется | Конструктор сайтов, не зависимость |

Правила в коде: длительности 100–260 мс, ease-out, opacity+transform, stagger ≤ 40 мс и ≤ 5 элементов, `prefers-reduced-motion` отключает transform; pulse статуса — только в состоянии `checking`; прогресс — только по данным события, без случайных приращений.

Размер бандла фиксируется по факту сборки в `TASKS.md`.
