# Threat model (v0)

Полная таблица угроз и мер — в [`SECURITY.md`](../../SECURITY.md). Здесь — активы и потоки, которые нужно проверять тестами в Фазах 2–5.

## Активы

1. SSH-доступ к серверам клиентов (приватные ключи ServerMind, закреплённые host keys).
2. API-ключи провайдеров (BYOK) и платформенный ключ.
3. Ledger кредитов.
4. Журнал аудита и истории операций.
5. Сессии и 2FA-секреты.

## Потоки и доверие

`Browser → Caddy → Next.js / FastAPI → PostgreSQL / Worker → SSH → VPS`. Единственный компонент, который выполняет команды на VPS, — worker, и только каталог одобренных операций. AI-ответы и логи серверов — недоверенные данные.

## Обязательные тесты безопасности (MD §4) → статус

| Тест | Фаза | Статус |
|---|---|---|
| подмена organization_id / IDOR | 2 | не реализовано |
| SSH fingerprint mismatch | 2 | UI-слой есть (демо-фикстура); backend не реализован |
| неизвестный tool от LLM | 3 | не реализовано |
| мутация без approval; изменённый hash; просроченный approval | 3–4 | клиентская часть hash/expiry проверена юнит-тестами (`lib/plan.test.ts`); серверной проверки нет |
| invalid hostname; SSRF | 2 | клиентская валидация проверена юнит-тестами (`lib/validation.test.ts`); серверной политики нет |
| DNS rebinding | 2 | не реализовано |
| prompt injection в логах | 3 | не реализовано |
| двойное списание | 5 | не реализовано |
| логирование API-ключей | 2–3 | в UI проверено e2e: ключ не попадает в DOM и browser storage (демо-режим); серверные логи не проверялись |
| worker cancel, concurrent deploy, перезапуск БД | 4–5 | не реализовано |
