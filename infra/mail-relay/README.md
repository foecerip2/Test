# Почтовый ретранслятор LeadHunter (хостинг Рег.ру)

VPS закрывает исходящие порты 25/465/587, поэтому коды входа уходят так: VPS → HTTPS → маленький PHP-скрипт на вашем хостинге Рег.ру → почтовый ящик `noreply@vaylonet.ru` → получатель. Скрипт умеет только одно: отправить письмо «Код входа LeadHunter» (6 цифр) — произвольный текст он не примет. Все запросы подписаны общим секретом.

## Установка с телефона (≈10 шагов)

1. **VPS (консоль 1cent.host).** Выполните `lh-config mail-relay` и нажмите Enter, чтобы принять адрес по умолчанию.
2. Команда покажет **секрет** (длинная строка). Скопируйте его целиком — он показывается один раз.
3. Откройте панель хостинга Рег.ру (ISPmanager) → **«Shell-клиент»** (может называться «Терминал»).
4. Вставьте и выполните одной командой:
   ```
   curl -fsSL https://raw.githubusercontent.com/foecerip2/Test/main/infra/mail-relay/setup.sh | bash
   ```
   Если скрипт пишет «каталог сайта не найден» — выполните `ls ~/www`, найдите папку сайта и добавьте в конец команды ` -s -- --webroot ~/www/ПАПКА` (после `bash`).
5. На вопрос **«Пароль почтового ящика»** введите пароль ящика `noreply@vaylonet.ru` (символы не отображаются) и Enter.
6. На вопрос **«Секрет ретранслятора»** вставьте секрет из шага 2 и Enter.
7. В конце должна быть строка **«Самопроверка: ОК»**. Если там 401 — секрет введён неверно, повторите шаги 4–6. Если «адрес недоступен» — откройте `https://vaylonet.ru` в браузере; при необходимости выпустите бесплатный SSL в разделе «SSL-сертификаты» панели.
8. Вернитесь в консоль VPS: `lh-config smtp-test ВАШ@EMAIL` — придёт письмо с тестовым кодом (проверьте и «Спам»).
9. Если письмо пришло: `lh-config owner ВАШ@EMAIL`.
10. Не пришло — посмотрите журнал ретранслятора: Менеджер файлов → `lh-mail-data/lh-mail.log` (в домашнем каталоге).

Повторный запуск `setup.sh` безопасен: существующий конфиг можно оставить как есть (ответ Y) или перезаписать (n) — например, при смене секрета.

## Что где лежит

| Что | Где |
|---|---|
| Скрипт | `~/www/vaylonet.ru/lh-mail.php` |
| Конфиг (пароль и секрет, права 0600) | `~/www/lh-mail-config.php` — выше каталога сайта |
| Данные и журнал | `~/lh-mail-data/` — вне сайта |

## Протокол

`POST` `application/json`, тело ≤ 2 КБ: `{"to":"user@example.com","code":"123456","ttl_minutes":10}` (лишние поля запрещены).
Заголовки: `X-LH-Timestamp` (unix-секунды, допуск ±300 с), `X-LH-Nonce` (16–64 символа `[A-Za-z0-9_-]`, повтор отвергается), `X-LH-Signature` = hex HMAC-SHA256(секрет, `timestamp.nonce.тело`).
Ответы: `200 {"ok":true}`; ошибки `{"ok":false,"code":...}` с кодами 400 (`bad_request`, `https_required`), 401 (`unauthorized`), 405, 413 (`too_large`), 429 (`rate_limited`), 500 (`config_error`, `internal`), 502 (`send_failed`).
Лимиты: 5 писем в час на получателя и 300 в сутки всего.
