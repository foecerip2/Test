# Android-приложение LeadHunter

Приложение (`apps/android`, Capacitor) — тонкая оболочка: открывает `https://ai.vaylonet.ru`. Весь интерфейс и логика живут на сайте, поэтому любое обновление сайта на сервере сразу видно в приложении, без переустановки. Пакет: `ai.vaylonet.leadhunter`, Android 7.0+ (API 24).

## Установка
1. Скачайте `LeadHunter.apk` (GitHub → Releases → `android-N`, либо файл из чата).
2. Откройте файл и разрешите установку из этого источника.
3. При первом запуске появится окно «Вход на сайт»: логин `owner` и временный пароль сайта (хранится на телефоне, в APK не вшит). После внедрения настоящей авторизации (Фаза 2) это окно исчезнет.

## Что внутри
- Навигация ограничена доменом `ai.vaylonet.ru`; нет нативных функций, доступных удалённому содержимому, кроме интернета.
- Нет соединения → локальная страница «Не удаётся подключиться» с кнопкой «Повторить».
- Резервное копирование данных приложения отключено.

## Сборка
- GitHub: Actions → «Android APK» → Run workflow (или автоматически при изменениях в `apps/android/**` в `main`). APK попадает в Releases.
- Локально: `pnpm install && cd apps/android && npx cap sync android && cd android && ./gradlew assembleRelease` (нужны JDK 21 и Android SDK 36).

## Ограничения
- Ключ подписи временный: каждая сборка подписана новым ключом, поэтому новый APK нельзя поставить поверх старого — сначала удалите приложение (данные на сервере). Стабильный ключ потребуется для RuStore/Google Play и сделает обновления «поверх» возможными.
- APK не запускался на реальном телефоне в среде разработки (проверены подпись, манифест и конфигурация).
- iOS и версия для ПК не делаются (решение владельца).
