# LeadHunter AI — дизайн-пакет для Claude

**Внутри:** работающий интерактивный UI-макет (без backend), 8 экранов, дизайн-система, полное ТЗ, реализационная инструкция, готовый промпт.

## Как открыть макет
- Открой `index.html` в Chrome/Firefox/Safari; интернет не нужен для функциональности макета. Внешний Google Fonts опционален, есть системные шрифты fallback.
- Для локального сервера: `python3 -m http.server 8080` в директории архива → `http://localhost:8080/`.
- Меняй разделы в левой панели. В разделе «База компаний» работают поиск, фильтр и CSV экспорт. В «Согласовании» можно менять канал, редактировать и копировать текст, согласовать черновик. В «Диалогах» работают переключение переписок и копирование ответа. Меню адаптировано под телефон.
- **Никакой реальной рассылки или сетевого парсинга нет.** Компании и метрики вымышлены, присутствуют только для дизайна.

## Файлы
- `index.html` — интерактивный макет.
- `assets/styles.css` — дизайн-токены и адаптивные стили.
- `assets/app.js` — client-side логика демонстрации, без вызовов API.
- `DESIGN_SYSTEM.md` — дизайн-язык, UX, анти-AI-slop.
- `PRODUCT_TZ_REFERENCE.md` — предыдущая спецификация MVP (для согласования требований).
- `CLAUDE_IMPLEMENTATION.md` — основная подробная инструкция по реализации.
- `START_PROMPT_FOR_CLAUDE.md` — готовая команда для Claude.

## Критически важное
1. Интерактивный прототип — визуальная цель, а не доказательство работающего backend.
2. Не подменять реальные показатели демоданными после подключения backend.
3. Разделить одобрение текста и право на рекламную отправку; без подтверждения разрешения — **не отправлять**.
4. Физлицу могут быть недоступны отдельные бизнес-API и лицензии.
5. Для production придерживаться GitHub CI/CD, безопасного развертывания и тестирования.
