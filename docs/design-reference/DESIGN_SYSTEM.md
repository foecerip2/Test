# LeadHunter — дизайн-система v1.0

## Дизайн-направление
**Calm Operations / Editorial SaaS**. Не «нейросеть из будущего», а профессиональный инструмент продаж, которому доверяют. Вдохновение: высококачественные B2B-консоли с хорошим информационным дизайном, тактильными поверхностями, сильной сеткой, умеренной типографикой и понятными состояниями. Визуал не копировать с чужого сайта.

### Чего не должно быть (ANTI-AI-SLOP)
- Никаких фиолетово-розовых градиентов, подсвеченных сфер, 3D-мозгов, «космических» текстур, случайных стеклянных панелей.
- Никаких одинаковых карточек на каждом экране, огромных безосновательных отступов и неуместных анимаций.
- Никаких фиктивных работающих кнопок, фейковой активности, псевдо«live»-статусов, выдуманных отзывов в продуктовой версии.
- Не использовать эмодзи в основном UI как замены системным иконкам.
- AI — вспомогательный инструмент, а не главный герой брендинга. Не писать «магия ИИ».

Статус никогда не кодируется только цветом: всегда текст/иконка. В рабочем приложении проверять WCAG AA с реальными шрифтами и плотностями.

## Шрифты
- Основной: `DM Sans`, fallback системный sans (для кириллицы используется fallback при неполном покрытии).
- Заголовки: `Manrope`, fallback системный sans.
- Должно корректно работать **офлайн без Google Fonts** за счёт системных fallback. На production лучше self-host только лицензированные webfont-файлы; не брать шрифты из непроверенных источников.
- Размеры desktop: page 28px, section 14–16px, body 12–14px, meta 10–11px. Для production UI не уменьшать основной содержательный текст ниже 13–14px; макет плотный для обзорной демонстрации.

## Геометрия
- Desktop sidebar 252px, header 72px, content max 1440px.
- Desktop content padding 42px, grid gap 14–18px.
- Cards border 1px, radius 10–13px, лёгкая почти незаметная тень.
- Кнопки от 37px; в production mobile hit targets >=44px.
- Mobile: sidebar превращается в выезжающее меню, одна колонка, горизонтальный скролл у таблиц, без обрезания контента.
- Breakpoints: 1150, 950, 700px. Тестировать 360, 390, 768, 1024, 1440px.

## UX правила
1. Слева навигация; рабочая зона справа; одна главная CTA на экран.
2. Любая компания: источник + дата + подтверждённые факты + неподтверждённые гипотезы.
3. Любое сообщение: версия текста + канал + разрешение контакта + состояние утверждения + журнал отправки.
4. Статусы: `new → analyzed → draft_ready → awaiting_approval → approved → sending → sent → replied`, отдельные `blocked`, `refused`, `failed`, `manual_only`.
5. Согласование текста НЕ даёт права отправить без доказательства разрешения адресата.
6. Реальные показатели нельзя подменять демонстрационными. Sample data только с меткой `Демо`.
7. AI-ошибки и отсутствие AI не блокируют поиск, карточки компаний и ручную CRM.
8. Работа на телефоне — приоритет. Поддерживать клавиатуру, screen readers, reduced motion и фокус.

## Микроанимации
- Hover/focus 120–180 мс, translateY(1px) только для кнопки при нажатии.
- Drawer/menus 180–240 мс, без bounce.
- Skeleton только на реальной загрузке, не постоянный декоративный shimmer.
- `prefers-reduced-motion: reduce` полностью выключает движение.
- При реализации в React использовать CSS transitions; Framer Motion только для действительно сложных переходов.

## 8 целевых экранов
1. Overview — KPI, приоритеты и активность.
2. Discovery — поиск по всей России, категории, источники, задания.
3. Leads — таблица, фильтры, доказательства, история.
4. Approvals — AI-черновик, редактирование, канал и проверка согласия.
5. Inbox — ответы, авто-классификация, отказ/интерес.
6. Pipeline — стадии продаж.
7. Analytics — реальная воронка и качество данных.
8. Settings — API/интеграции/безопасность.

## Макет и production
`index.html`, `assets/styles.css`, `assets/app.js` — интерактивный прототип. Это НЕ готовый продукт. В нём нет backend, реальных API и отправки сообщений. Production надо реализовать на Next.js/FastAPI согласно основному ТЗ, без копирования демонстрационных чисел или фиктивных карточек в реальную БД.
