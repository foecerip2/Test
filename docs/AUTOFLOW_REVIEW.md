# Проверка дизайна и реализации AutoFlow

Применены локальные навыки Claude: `ui-ux-pro-max` (направление и система интерфейса), `browser-qa` (взаимодействие и визуальная проверка), `security-review` (права, вход, данные и зависимости), `verification-loop` (сборки, типы, линт и тесты). Для длительностей использован справочник `review-animations/STANDARDS.md`.

## Решения по дизайну

Замечания исходного мобильного экрана: тяжёлые кнопки с объёмной тенью, широкая гарнитура заголовка, перегруженный первый экран, продукт расположен слишком далеко от заголовка. Новая версия использует белые/светлые поверхности, графитовый текст, синий акцент, компактные кнопки и превью настоящего назначения продукта — расписания. Лендинг, вход и кабинет имеют общие токены. Onest остаётся локальным шрифтом с кириллицей; внешних запросов к Google Fonts нет.

Автоматический поиск `ui-ux-pro-max` дал SaaS hero-first и спокойную motion-интенсивность. Предложенные им акцент красного цвета и широкая Syncopate не использованы: для русскоязычного расписания выбраны более спокойные цвета и читаемая Onest.

Данные в превью лендинга явно помечены как пример. Счётчики и записи в приложении приходят из API. Нет выдуманных клиентов, тарифов, выручки и отзывов.

## Движение

Однократное появление hero и секций, реакция кнопок и подтверждение записи в иллюстрации. Диалог — 200 мс, нажатие — 160 мс; используются opacity/transform. Частые рабочие действия не сопровождаются длинными анимациями. При reduced-motion анимации и плавная прокрутка отключаются. Для просмотра и управления не требуется анимация.

## Проверено

- Регистрация/вход, ожидание доступа, повторный вход, серверное хранение и разграничение продуктов.
- Создание автосервиса, услуги, бокса, записи, сохранение после reload, конфликт времени и изменение статуса.
- Приём заявки с лендинга и обработка внутри приложения.
- Клавиатура в диалоге: Tab, Escape, возврат фокуса. Исправлена потеря фокуса после ошибки сохранения.
- Axe WCAG 2 A/AA и 2.1/2.2 AA для лендинга, входа/регистрации и рабочего экрана на desktop/mobile. Это автоматическая проверка, не полная сертификация доступности.
- Отсутствие горизонтальной прокрутки и поддержка reduced-motion. Скриншоты — `docs/screenshots/autoflow/v2-*`.
- Проверка прав API, CSRF/Origin, изоляция рабочих данных и сессий, конкурентная запись в PostgreSQL.
- PostCSS обновлён; production dependency audit: известных уязвимостей не обнаружено.

Локально: API — 1008 passed, 1 skipped (PHP отсутствует); unit AutoFlow — 23 passed; unit LeadHunter — 299 passed; браузер AutoFlow — 35 passed, 1 skipped; браузер LeadHunter — 124 passed, 4 skipped. Визуальные проверки: ширины 375, 768, 1440, без горизонтальной прокрутки и uncaught JS errors; отдельные браузерные сценарии — 390 и 1440. Отдельно добавлена проверка доступности московской таймзоны без системной базы zoneinfo (для slim Docker). Состояние GitHub CI см. в PR. Покрытие кода в процентах и полевые Core Web Vitals не измерялись. Настоящая доставка OTP и установка APK на физический телефон проверяются отдельно.
